# Global browser profile snapshot — 2026-07-31, revision 2

`global_2026-07-31-r2.json` is the default weighted profile distributed with Apex UA Rotator since 1.3.0. It is a corrected revision of `global_2026-07-31.json`, which remains bundled unchanged so earlier results can be reproduced.

## What changed in revision 2

One entry was corrected. The ChromeOS User-Agent now carries the frozen platform token `X11; CrOS x86_64 14541.0.0`. Under Chromium's User-Agent reduction, Chrome sends that literal value on every ChromeOS version. Revision 1 used `X11; CrOS x86_64 16700.60.0`, a value current Chrome builds never send, so it would have stood out from real traffic.

Weights, ordering, and the other 62 entries are unchanged. The metadata records the change in `profile_revision`, `supersedes`, and `revision_notes`.

## Snapshot properties

- 63 unique User-Agent strings
- raw weights totaling exactly 100
- entries ordered from highest to lowest weight
- desktop, mobile, and tablet coverage
- dated metadata and a versioned JSON schema

## Modeling approach

The matrix is a pragmatic global model rather than a census. Platform and browser-family shares were reconciled with operating-system compatibility constraints, then divided among current, previous, and retained browser versions. Exact cross-dimensional telemetry is incomplete, so small cells and version adoption are modeled estimates.

The profile deliberately excludes crawler identities, headless tokens, fabricated devices, and browser/engine combinations that could not be supported confidently. Every Chromium-based entry uses the reduced User-Agent format (`<major>.0.0.0` versions and the frozen platform tokens), except Chrome on iOS (`CriOS`), which reports full versions.

## Maintenance

Treat the file as replaceable data, not permanent application logic. Browser releases and traffic distributions change continuously; the `as_of` date says how current the model is. Keep dated files for reproducibility and publish a new dated profile or a numbered revision rather than silently rewriting an old snapshot.

## Fingerprint boundary

A User-Agent header is only one part of an HTTP or browser identity. This profile does not align Client Hints, TLS behavior, HTTP/2 settings, JavaScript-visible properties, viewport, locale, cookies, proxy location, or request pacing.
