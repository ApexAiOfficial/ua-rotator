# Global browser profile snapshot — 2026-07-31

`global_2026-07-31.json` is the default weighted profile distributed with Apex UA Rotator.

## Snapshot properties

- 63 unique User-Agent strings
- raw weights totaling exactly 100
- entries ordered from highest to lowest weight
- desktop, mobile, and tablet coverage
- dated metadata and a versioned JSON schema

## Modeling approach

The matrix is a pragmatic global model rather than a census. Platform and browser-family shares were reconciled with operating-system compatibility constraints, then divided among current, previous, and retained browser versions. Exact cross-dimensional telemetry is incomplete, so small cells and version adoption are modeled estimates.

The profile deliberately excludes crawler identities, headless tokens, fabricated devices, and browser/engine combinations that could not be supported confidently.

## Maintenance

Treat the file as replaceable data, not permanent application logic. Browser releases and traffic distributions change continuously. Keep the dated file for reproducibility and publish a new dated profile rather than silently rewriting an old snapshot.

## Fingerprint boundary

A User-Agent header is only one part of an HTTP or browser identity. This profile does not align Client Hints, TLS behavior, HTTP/2 settings, JavaScript-visible properties, viewport, locale, cookies, proxy location, or request pacing.
